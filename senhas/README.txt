          📁 CENTRAL DE SENHAS INDIVIDUAIS DOS STREAMINGS
================================================================================

Esta pasta contem os arquivos de senhas avulsas geradas para cada streaming:

• SENHA_NETFLIX.txt      -> Senha exclusiva que libera apenas Netflix
• SENHA_HBO.txt          -> Senha exclusiva que libera apenas HBO Max
• SENHA_SKY.txt          -> Senha exclusiva que libera apenas Sky+
• SENHA_CRUNCHYROLL.txt  -> Senha exclusiva que libera apenas Crunchyroll
• SENHA_NETFLIX_HBO.txt  -> Senha duo que libera Netflix + HBO Max
• SENHA_COOKIES.txt      -> Senha do cofre de cookies interno

💡 DICA: Para gerenciar, criar novas senhas com qualquer combinacao de streamings
e revogar acessos, utilize o Painel de Controle Admin em:
